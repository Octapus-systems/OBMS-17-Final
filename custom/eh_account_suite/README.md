# Odoo 19 Community Accounting Pro

One-click install for the entire ERP Heritage accounting suite on Odoo
19 Community Edition.

## What this module does

This is a meta module. It has no models, no views, and no data of its
own. Installing it pulls in 27 production-grade accounting modules
published by ERP Heritage onto the Apps Store, at a coherent version.

## What is included

| Capability | Module |
|---|---|
| Foundation | `eh_account_base`, `eh_account_setup` |
| Reporting | `eh_account_dynamic_reports`, `eh_account_dynamic_reports_pro`, `eh_account_dashboard` |
| Receivables | `eh_account_reconcile_pro`, `eh_account_bank_statement_import`, `eh_account_batch_payment`, `eh_account_collections`, `eh_account_credit_limit`, `eh_account_recurring_invoices`, `eh_account_pdc`, `eh_account_portal_extra` |
| Payables | `eh_account_ap_automation`, `eh_account_approval` |
| Assets / leases | `eh_account_assets_pro` |
| Period close | `eh_account_close_workflow`, `eh_account_year_end`, `eh_account_fx_revaluation` |
| Group accounting | `eh_account_intercompany`, `eh_account_consolidation` |
| Budgeting | `eh_account_budget_pro` |
| Compliance | `eh_account_einvoice_peppol`, `eh_account_l10n_au_bas` |
| Payment files | `eh_account_sepa_ct`, `eh_account_sepa_dd` |
| Augmentation | `eh_account_ai_agent` |

## Why install the bundle

* **One version stream.** Every constituent module is on the same Odoo
  19 release line. The bundle anchors the combination tested as a set.
* **One support contact.** All modules from one publisher.
* **One install.** No hunting through 27 separate Apps Store listings.
